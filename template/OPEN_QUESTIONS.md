# Open Questions

คำถาม / assumption ที่ยังไม่ confirm ใช้เป็นจุด review ก่อน launch
ก่อน launch จริง ควรเอาไฟล์นี้ไปคุยกับคนรู้จริง (เพื่อน senior, community, paid review)

## Format

```
- [type] question/assumption — context — owner — deadline
```

**type:**
- `[assumption]` — AI ตัดสินใจเอง รอ user confirm
- `[security]` — ต้อง review จากคนรู้เรื่อง security
- `[architecture]` — ต้อง review จาก senior
- `[business]` — ต้อง user ตัดสินใจ
- `[research]` — ต้อง search docs/community เพิ่ม
